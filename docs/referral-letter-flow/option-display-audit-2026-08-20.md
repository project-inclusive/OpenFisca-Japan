## 実装上の引き継ぎ経路

1. [`config.ts`](../../dashboard/src/components/referral-letter/config.ts) の静的設定から質問と選択肢を取得する。
2. [`QuestionScreen.tsx`](../../dashboard/src/components/referral-letter/screens/QuestionScreen.tsx) が選択肢の `label` を加工せずボタンへ表示する。
3. [`logic.ts`](../../dashboard/src/components/referral-letter/logic.ts) が選択済み回答の `label` を `answerLabel` として候補へ引き継ぐ。
4. [`ConcernScreen.tsx`](../../dashboard/src/components/referral-letter/screens/ConcernScreen.tsx) と [`OtherConcernScreen.tsx`](../../dashboard/src/components/referral-letter/screens/OtherConcernScreen.tsx) が `answerLabel` を加工せず表示する。
5. [`ReferralDocumentView.tsx`](../../dashboard/src/components/referral-letter/components/ReferralDocumentView.tsx) が生成文書の回答文を加工せず表示する。

この経路に、回答文の要約、置換、別分野との結合はない。

## 監査の境界

- 本監査は、2026-08-20時点のGoogle Sheets「決定版」と現在のローカル実装が一致しているかを確認したもの。
- シート原文そのものの日本語表現、制度上の妥当性、紹介先の適切性は対象外。
- たとえば `該当しない` と `該当なし` の違いは、分野ごとの決定版シートに記載された文字列どおりに表示されている。
- 実画面確認はCypress Electronによる。実機Safari等のフォント描画差は本監査の対象外。
