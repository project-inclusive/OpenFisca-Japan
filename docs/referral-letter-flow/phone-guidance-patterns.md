# 電話案内：修正内容と全表示パターン

## 対応内容

説明書の電話案内に、選択した主な困りごとのカテゴリ名を差し込むよう修正しました。

表示形式：**市町村の代表番号に電話し「【カテゴリ名】について相談できる窓口を知りたい」と伝える**

具体的な回答やその他の困りごとは、この電話案内には差し込みません。主な困りごとを変更して文書を再生成すると、そのカテゴリの案内に変わります。「窓口に連絡し『紹介状に記載された困りごとについて相談したい』と伝える」という別の案内文は変更していません。

今回の対象は電話案内のみです。修正版9.10のデータ更新、紹介先の2件化、リンク追加、印刷レイアウト変更は行っていません。

## 確認結果

- 現行の全107候補回答について文書生成関数を直接実行し、主な困りごとのカテゴリ名が正しく入ることを確認しました。21カテゴリ・14種類の文言を網羅しています。
- 別の連絡案内文が変更されていないことも同時に確認しました。
- 既存Cypressの全候補回答テストの期待値を更新しました。ただし、この環境ではCypress本体が未インストールのため、Cypress実行はできていません。
- `npm run build`、`npm run lint`、変更したコード・テストのPrettierチェックは成功しました。ビルドには既存の `use client` とバンドル容量に関する警告があります。
- ブラウザ画面、保存PNG、印刷プレビューの実機確認は今回未実施です。これらが参照する共通の文書生成処理を修正しています。
