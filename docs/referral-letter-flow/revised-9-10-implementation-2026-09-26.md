# 紹介状機能 修正版9.10 対応記録（2026-09-26）

## 実装した内容

| 項目 | 対応内容 |
| --- | --- |
| 対応表 | 高齢・子育て・若者の「修正版9.10」全126回答を静的設定に取り込み。実行時のSheets接続なし |
| 緊急度 | 「緊急度合 新」の無・低・中・高を採用。数値換算を廃止し、「無」は候補から除外 |
| 相談先 | 例示ごとの紹介先①②とURL①②を順序どおりに保持。推測の相談先補完を廃止 |
| 電話・検索案内 | 主な困りごとの相談先ごとにURLの有無で分岐。電話は連絡先が見つかった場合のみ案内 |
| リンク表示 | 「案内ページを開く」または「案内ページのリンクなし」。URL文字列も掲載し長いURLは折り返す |
| 説明書 | 用途を見出しの下に中央揃えで追加。相談先、主な困りごとの緊急度、免責文を表示 |
| 紹介状 | 用途と免責文を追加。相談先と緊急度は非表示。困りごとの具体、任意入力、作成主体を維持 |
| 印刷 | 紹介状の直前に印刷専用の切り取り線を追加。A4縦・自然な複数ページを許容 |
| PNG | 説明書と紹介状のみ。URL・免責文を含め、切り取り線と操作部分は非表示 |
| 保存データ | v2へ更新。旧v1の回答・選択・同意・氏名等を破棄し説明画面から開始。v2は再読み込みで復元 |

API・OpenFisca・既存見積もりの契約は変更していません。コミット、プッシュ、本番反映は行っていません。

## 案内の表示パターン

| パターン | 実データの代表例 | 案内 |
| --- | --- | --- |
| 相談先1件・リンクなし | お金／生活が送れない | 相談先名＋市町村名＋電話番号で検索 |
| 相談先1件・リンクあり | お金／家賃もしくはスマホ料金を滞納 | 案内ページで地域の連絡先や必要な情報を確認 |
| 相談先2件・①なし②あり | 高齢・移動／通院、日常的な買い物（食材等）の手段がない | ①を検索、②は案内ページを開く |
| 相談先2件・①あり②なし | 身体的健康／お金の支払いが難しく受診できていない | ①は案内ページを開き、②を検索 |
| 相談先2件・両方あり | 若者・仕事／現在働いておらず働こうとも思えない | それぞれの案内ページを開く |

相談先2件で両方リンクなしの回答は今回の原表にはありません。各相談先の分岐は独立しているため、その場合もそれぞれ検索案内になります。
