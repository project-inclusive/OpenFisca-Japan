# 紹介状機能 納品先への確認事項

2026年8月18日時点の実装と、Google Sheets各「決定版」タブの設定を前提にした確認表です。

回答欄には `合意`、`要修正`、`対象外` のいずれかと、担当者・回答日を記入してください。

## 優先度の定義

- **P0**：β版を利用者へ公開する前に合意が必要
- **P1**：納品受入または運用開始までに決める
- **P2**：β版運用中に検証し、正式版までに決める

## 納品判定の最小条件

- P0-1〜P0-9がすべて `合意` または対応内容を確定している。
- 回答別の紹介先と表示文を、分野責任者と相談先・制度に詳しい担当者が承認している。
- 空欄4回答の紹介先が、シート記入または明示的なフォールバックとして承認されている。
- 402px以下で発生する「トップページへ戻る」ボタンの表示崩れについて、修正または受入判断が完了している。
- β版の対象、期間、問い合わせ先、評価方法、正式版移行の判断者が決まっている。
