# 紹介状機能 検収チェックリスト（先方確認用）

- 対象機能：紹介状 β版 V1
- 更新日：2026年9月6日
- 対象画面：トップページ右下の「紹介状 β版」から始まる一連の画面

## この資料の目的

紹介状機能について、次の3点を専門知識なしで確認できるようにした資料です。

1. どのような目的・仕様で実装したか
2. 画面上でどのように確認するか
3. どの状態なら検収合格と判断できるか

検収時にプログラムや開発者向けツールを見る必要はありません。表の「確認操作」を上から順に実施し、「合格条件」と同じ結果になれば「判定」欄を `○` にしてください。

### 判定の記入方法

| 記号 | 意味                                 |
| ---- | ------------------------------------ |
| ○    | 合格条件どおりになった               |
| ×    | 合格条件と異なる、または操作できない |
| 保留 | 判断できないため開発側への確認が必要 |
| ―    | 今回の検収対象外                     |

> 検収では実在する氏名やメールアドレスを使わず、`検収用 太郎`、`test@example.com` などのダミー情報を使用してください。問題があった場合は、チェック番号、操作した内容、画面のスクリーンショットを記録してください。

### おすすめの進め方

1. まず1つの分野で、入口から紹介状の完成までを通して確認する
2. 次に、未選択、メール形式エラー、困りごとなしなどの分岐を確認する
3. 最後に、画像保存、印刷、再読み込み、最初からやり直すを確認する
4. 画面操作だけでは判断しにくい項目は「当方で確認済みの実装証跡」を確認する

## 実装の前提

| 項目           | 想定している仕様                                                                                        |
| -------------- | ------------------------------------------------------------------------------------------------------- |
| 機能の目的     | 質問への回答から困りごとと相談先を整理し、利用者が窓口で見せられる「説明書」と「紹介状」を作る          |
| 提供方法       | β版のため、通常の「かんたん」「くわしく」と分け、トップページ右下のフロートボタンから開始する           |
| 対象分野       | 高齢分野、子育て（乳幼児）分野、若者（社会人）分野の3分野                                               |
| 質問データ     | 各分野の「決定版」シートをもとに、各7問と回答選択肢、緊急度、紹介先をアプリ内に固定データとして組み込む |
| 判定の位置づけ | 医療・福祉上の診断や、支援を受けられるかどうかの決定は行わない                                          |
| データの扱い   | 入力内容はサーバーへ送信せず、利用中のタブの `sessionStorage` にだけ保持する                            |
| 出力           | 画面表示、PNG画像の保存、PC向け印刷に対応する。窓口への自動送信は行わない                               |
| 対象外         | 共有URL、QRコード、切り取り線、OpenFiscaへの回答連携、紹介状データのAPI・DB保存                         |
